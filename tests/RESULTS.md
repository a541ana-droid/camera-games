## 2. حيل الاستعادة (m21) — ماذا جُرّب وماذا نجح
جُرّبت داخل Worker بعد التعطيل، في iframe وhost، وفي Safari أيضًا:
| الحيلة | النتيجة |
|---|---|
| المشي على سلسلة النماذج الأولية للـglobal بحثًا عن `fetch/XHR/WebSocket/EventSource/importScripts/Worker/SharedWorker/WebTransport/BroadcastChannel/indexedDB/caches/RTC/sendBeacon/openDatabase` | لا شيء (`none`). **أول مرة كشف الاختبارُ ثغرتين فعليتين وأُغلقتا:** `StorageBucket.prototype.indexedDB/caches` (واجهة Storage Buckets، تصل عبر `navigator.storageBuckets`) — أُضيفتا للقائمة؛ بعدها `none` |
| `globalThis` / `(function(){return this})()` / `typeof self[name]` | لا شيء |
| `eval` / `(0,eval)` / `new Function` / `[].constructor.constructor` / منشئات async وgenerator / `setTimeout("نص")` | **محجوبة بـCSP** (`EvalError`)؛ `setTimeout("R.ts=1")` تُقبل ولا تُنفَّذ أبدًا (`ts_ran:no`) |
| `import('data:…')`، `import('http://أصل-آخر/…')`، `import('http://أصل-المضيف/…')` | محجوبة (`TypeError`) في iframe؛ في host الأخيرة تُرسل GET ثم تفشل |
| `import(URL.createObjectURL(blob))` | **تنجح** (`script-src blob:` لازم لتحميل اللعبة نفسها) — تنفيذ كود من نص؛ لا تمنح صلاحية جديدة |
| إعادة تعريف `MessagePort.prototype.postMessage` / `Reflect.apply` / `Function.prototype.call` / `EventTarget.prototype.addEventListener` | **مجمّدة** (الإسناد لا يغيّر شيئًا؛ `defineProperty` ⇒ `TypeError`) |
| مشي الرسم البياني لـ~60 جذرًا (self، navigator، performance، منشئات، WebAssembly، Atomics، …) بحثًا عن دوال أصلية بأسماء الشبكة | 2841 كائنًا في iframe و3485 في host (و2942 في Safari): **لا شيء** |
| `new Worker(blob)` من داخل الـWorker (عالَم جديد غير معطَّل) | `ReferenceError` (محذوف) |
| الاستماع لرسائل `hello` | لا يصل؛ `hello` يُستهلك قبل تشغيل كود اللعبة (يعمل بعد `importScripts` داخل المعالج) |
| `self.postMessage` الخام (وعلى النموذج الأولي) | يرمي؛ 10 آلاف محاولة رُفضت |

### بدون طبقة التعطيل (`?nogate=1`، اختبار فقط): ما تغطيه CSP وحدها
| | وضع iframe (CSP `connect-src 'none'`) | وضع host (CSP `connect-src 'self'`) |
|---|---|---|
| شبكة (fetch/XHR/WS/SSE/importScripts/Worker) | **0 طلب وصل** (Chrome وSafari) | **7 طلبات وصلت كلها إلى أصل المضيف** (`fetch` و`xhr` و`import` و… إلى `127.0.0.1:8453`)؛ لا طلب واحد إلى الأصل الآخر `localhost:8453` |
| تخزين | محجوب (أصل `null`) | **مفتوح**: IndexedDB/Cache/`navigator.storage` (أصل المضيف) |
| eval/Function | محجوب | محجوب |
| `new Worker(blob)` متداخل | ينجح لكن يرث CSP (لا شبكة) | ينجح (عالَم غير معطَّل ويرث `connect-src 'self'`) |
| `self.postMessage` الخام | يصل للحاضن ويُهمَل | يصل للمضيف ويُحسب «stray» |
**الدلالة:** الاعتماد على التعطيل وحده في وضع host غير كافٍ؛ وضع iframe هو الأمتن (CSP تصمد لو فشل التعطيل).

## 3. حدود ومعروفة صراحةً (ما لا تغطيه كل طبقة)
| الطبقة | تغطي | لا تغطي |
|---|---|---|
| Worker (لا DOM) + المضيف لا يشغّل كود اللعبة | تجمّد الصفحة، الوصول إلى DOM/`window`/`parent`، قراءة صفحة المضيف | استنزاف CPU/بطارية ضمن النافذة؛ الذاكرة |
| `terminate()` + نبضة الإطار (2 ث) + boot (4 ث) | كل حلقات الاختبار (update/render/مؤقّت/ردّ تتبّع/init/top-level) | حلقة «حيّة بطيئة» تحت الميزانية؛ لا بدّ من إيقاف 2.0–2.3 ث من الحرق |
| iframe معزول + CSP للحاضن | شبكة وتخزين وeval حتى لو فشل التعطيل (مُثبَت بـnogate) | `import(blob:)` (≈eval)، استنزاف |
| CSP المستند (host) | eval، شبكة إلى أصول أخرى | **GET إلى أصل المضيف عبر `import()` (لا يُحذف: صيغة لغوية)**؛ تخزين أصل المضيف إن سقط التعطيل |
| طبقة التعطيل + التجميد داخل Worker | كل حيل الاستعادة المجرَّبة | ليست برهانًا؛ أي مرجع أصلي منسيّ يُرى فقط بمشي الرسم البياني (اكتشف اثنين اليوم) |
| تحقق المضيف من الرسائل/الإطارات | تزوير/سقف/أنواع/عمق save/نصوص | — |
| **الذاكرة** | 0.2.1 | عدّاد حجز داخل Worker (منشئات المصفوفات وArrayBuffer، مع FinalizationRegistry) + علامة سقوط الصفحة. لا يرى `push` التدريجي ولا النصوص/الكائنات؛ لم يُجرَّب على iOS بعد |
| الخداع البصري | — | اللعبة ترسم أي بكسل على canvas (نماذج مزيفة) |

## 4. دورة الحياة بلا إعادة تحميل (`node tests/run-lifecycle.mjs`) — 26/26 في iframe و26/26 في host
- **إطارات مزوّرة تُرسل مباشرة إلى معالج المضيف** (مرتبطة بقناة اللعبة): رمز أمر غير موجود، نص مكان رقم، `null`/NaN، وسائط مبتورة، 30000 عنصر، ليست مصفوفة، إطار بلا نبضة منتظرة، 100 `save` ⇒ **كلها تُحسب انتهاكًا والمضيف حيّ**؛ إطار صالح مزوّر يُرسم بلا انتهاك؛ رسائل `hud` ضخمة/`track.start` بلا قدرة/نوع مجهول/`audio.tone` بلا قدرة ⇒ انتهاكات.
- 3 دورات من `zz-loop-test.js`: سبب مقروء («اللعبة علقت (إطار لم يكتمل خلال ثانيتين…) فأُنهي عاملها فورًا. الصفحة سليمة…»)، `no-heartbeat`، **من `ready` إلى القتل 3.23 ث** (التعليق يبدأ بعد ثانية من init)، lag المضيف 1–2ms، لا حالة/حاضن/عامل والكاميرا مغلقة، نفس الصفحة، «إعادة» تُعيد اللعبة (والعامل الجديد يعمل)، «القائمة» تعمل.
- لعبة سليمة (`mole-air`) بعد التعليقات: 119 إطارًا في 2 ث، نفس الصفحة.

## 5. التراجع التلقائي إلى وضع host (`node tests/run-fallback.mjs`) — 3/3
محاكاة فشل إطلاق iframe (`?breaklauncher=1`): بعد 2.5 ث بلا `alive` ⇒ `fallback:alive-timeout` ⇒ `launch:host` ⇒ اللعبة تعمل (149 إطارًا)؛ الألعاب التالية في الجلسة تبدأ في host مباشرة؛ التعليق يُنهى في host أيضًا.

## 10. ما لم أستطع اختباره (بصراحة)
- **iPhone/iOS وSafari الجوّال** إطلاقًا (iOS 15 تحديدًا): حلقة الأحداث على الجهاز، `terminate()` هناك، سلوك الحاضن داخل iframe، `importScripts(blob)`. التراجع التلقائي يعالج فشل الإطلاق لكن لم أره يعمل على iOS.
- Firefox وأندرويد.
- **الذاكرة**: لا حارس، ولم أحاول استنفاد الذاكرة حقًا (مخاطرة بجهاز الاختبار).
- الكاميرا الحقيقية، عكس الأمامية في التتبع، دقة العتبات في إضاءة حقيقية (فقط فيديو اصطناعي).
- القياس النصي `measureText` للعربية تقريبي (جدول؛ لم أقارنه كميًّا بالقياس الحقيقي).
- الصوت صوتيًا والاهتزاز؛ معايرة اللون بالنقر ولقطة `camera.lowres` (مبنيتان من 0.1 ولم تُعاد اختبارهما آليًا).
- حدّ الإطار 8ms وعتبة الثانيتين على جهاز بطيء (قد تقتل لعبة سليمة)؛ الثوابت في أول engine.js (`BUDGET_MS`, `HB_TIMEOUT`, `BOOT_TIMEOUT`, `ALIVE_TIMEOUT`).
- تراجع iframe→host بسبب خطأ تحميل `NetworkError/SecurityError` للعبة (مبرمج، لم يُختبر؛ المختبَر هو تراجع `alive-timeout`).
- بعد تشغيل اختبارات Safari بقيت علامات تبويب Safari مفتوحة على `127.0.0.1:8453` في جهازك (لم أغلقها كي لا أطلب إذن أتمتة).
